# Jubeat Memo to StepMania Converter

# jubeatの創作譜面データ（テキスト形式／jubeatmemo）を、StepMania（DDR形式）の .sm ファイルに変換するGUIツールです。 「jubeatの縦4列」を「StepManiaの4レーン（Left, Down, Up, Right）」にマッピングして出力します。

# 

# 機能

# GUI操作: 直感的な操作でファイル選択や設定が可能。

# 

# ドラッグ＆ドロップ対応: テキストファイルをウィンドウに投げるだけで読み込み可能。

# 

# フォーマット自動判別:

# 

# 通常の jubeatmemo 形式

# 

# \#memo2 形式（パイプ | 内の文字数によるリズム定義、24分音符や変則リズム対応）

# 

# ヘッダー編集: .sm ファイルに必要な情報を編集可能。

# 

# TITLE, ARTIST, MUSIC, BPM

# 

# Difficulty（難易度名）, Level（数値）

# 

# 仕様:

# 

# レーン配置: Jubeatの左から順に StepManiaの \[Left, Down, Up, Right] に対応。

# 

# ホールドなし: ホールド記号（全角数字など）が含まれていても、始点のみを「通常ノーツ（Tap: 1）」として出力します。

# 

# 0小節目: 先頭に必ず空の小節（measure 0）を挿入します。

# 

# 必要要件

# Python 3.x

# 

# tkinterdnd2 ライブラリ（ドラッグ＆ドロップ用）

# 

# インストール

# Pythonがインストールされていることを確認してください。

# 

# 必要なライブラリをインストールします。

# 

# Bash

# 

# pip install tkinterdnd2

# 使い方

# jubeat2sm\_gui.py を実行します。

# 

# jubeat譜面のテキストファイル（.txt）をウィンドウにドラッグ＆ドロップするか、「ファイルを選択」ボタンから開きます。

# 

# 画面上の各項目を設定します。

# 

# TITLE / MUSIC: ファイル名から自動入力されます。

# 

# BPM: 曲のテンポを入力します（デフォルト: 100）。

# 

# Diff / Level: 難易度とレベル数値（デフォルト: 1）を設定します。

# 

# 「結果を保存」ボタンを押して .sm ファイルを書き出します。

# 

# 入力ファイルの形式について

# 以下の形式のテキストファイルに対応しています。

# 

# 基本形式

# 4行1セットでグリッドを表し、右側の | 内でタイミングを指定します。

# 

# Plaintext

# 

# 1

# □⑤①⑦ |①－②－|  <-- ①(0拍), ②(2拍)

# ①□□⑥ |③－④－|

# ②⑦⑦⑤ |⑤－⑥－|

# □③④□ |－－⑦－|

# \#memo2 形式（可変リズム）

# 右側の文字数によってリズムが変わります。

# 

# |①②③④| (4文字) = 16分音符

# 

# |①－②－③－| (6文字) = 24分音符 (6連符)

# 

# |①②③| (3文字) = 12分音符 (3連符)

# 

# ※ 全角数字（１, ２...）はリズム計算には使用されますが、ノーツとしては出力されません（ホールド終点無視仕様）。

# 

# 変換ロジック

# Jubeatの4x4パネルを縦にスライスしてマッピングします。

# 

# 列1 (パネル 1, 5, 9, 13) → Left

# 

# 列2 (パネル 2, 6, 10, 14) → Down

# 

# 列3 (パネル 3, 7, 11, 15) → Up

# 

# 列4 (パネル 4, 8, 12, 16) → Right

# 

# 同一列に複数のノーツがある場合（例：パネル1と5の同時押し）、StepManiaでは配置できないため、1つのノーツとして処理されます。

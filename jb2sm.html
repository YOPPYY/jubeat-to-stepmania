01譜面を読み込む

sonicy memo / cosmos memo などのページから、曲情報から譜面末尾までをコピーして貼り付けてください。複数の難易度をまとめて貼り付けると、1つの .sm に入ります。

.txt / 保存したページの .html に対応。ホールドの矢印・線を含めて、必ず譜面の最初から取り込んでください。

譜面をコピーするブックマーク

次のリンクをブックマークバーへドラッグして登録します。元の譜面ページ（cosmos memo など）を開いてそのブックマークを押すと、曲名・アーティスト・難易度・Level・BPM・Notes と譜面部分だけをクリップボードにコピーします。上の入力欄に貼り付けてください。

memoをコピー

開いているページの本文から必要な部分を抜き出すだけで、外部への送信はありません。

02曲情報・タイミング01 に譜面を入力すると使えます

—
出力元の難易度SM の難易度レベルNotes
「曲情報を読み取る」で表示されます

音源ファイル名は「曲名＋拡張子」が自動で入ります（拡張子は .mp3 / .ogg から選択）。「選択」で実際のファイルを選ぶと、その名前に変わります。音源を選んだ場合は再生にも使います。バナー・背景は banner.png / bg.png が初期値です。ファイル自体は同梱されないので、SMと同じフォルダーに置いてください。OFFSETの正値は譜面を早めます。

BPM変化を手入力する

譜面中に「BPM: 205」のような行があれば、次の小節の頭から変化するものとして拍位置を自動計算します（ここは空欄のままでOK）。入力した場合はこちらを優先します。拍位置は曲頭からの四分音符の累計です。変拍子では小節番号×4にはなりません。

03譜面オプション01 に譜面を入力すると使えます

—

フリーズアロー：例えばパネル1をホールド中に、同じ列のパネル5・9・13にノーツがなければ、元の長さのフリーズにします。重なる場合は始点のタップのままです。ホールド優先：ホールド中に同じ列へ来るタップを消して、ホールドをフリーズにします。

例：16分の3連打 → 1つ目から4つ目のタイミング（最後＋1間隔）までのフリーズ。

ホールド最優先：ホールドの始点（「始点と終点をタップ」では終点も）を先に残し、ホールド以外のノーツから削ります。ホールドどうしが3つ以上重なるときは上の優先順で選びます。フリーズ中のレーンも1つとして数え、合計2つを超えないようにします。オフのときは3〜4枚の同時押しもそのまま出力します。

4パネルへの割り当て（盤面の回転）

jubeat の盤面を回転してから、縦の列を左から ← ↓ ↑ → に割り当てます。図は元の盤面の各パネルがどの矢印になるかを示します。同時刻・同レーンに重なるノーツは1つに統合します。

予想サイズ：—

        
        
今の表示（レイアウト・パネルごとの設定・音量・クラップ）のまま、実際の再生より速く .webm 動画を作ります。サイズは 1:1 なら 720×720 / 1080×1080、16:9 なら 1280×720 / 1920×1080 です。小節を指定すると、開始小節の1拍前から終了小節の終わりまでを書き出します。

      

    

    
    

      
    

    
画面をタップすると再生／一時停止します。「全画面」で再生画面だけを大きく表示できます。

    
Space：再生／一時停止　← →：5秒移動　↑ ↓：ハイスピード　[ ]：OFFSET ±10ms　Shift＋[ ]：±100ms　R：Reverse　H：ホールドマーカー　Enter：選択した小節の頭から再生　L：ループ切替　（別ウィンドウでも同じキーが使えます。画面クリックでも再生／一時停止）
ノーツが音より遅れて見える・クラップが遅れて聞こえるときは OFFSET を増やしてください。変更した OFFSET は保存する .sm にもそのまま反映されます。StepMania 側のオレンジの線と番号は、元の jubeat の小節線です。

  

  
  
変拍子に対応。リズム行 |…| は1行を1拍として文字数で等分します（4文字＝16分、6文字＝24分、8文字＝32分）。1・2文字の短い行だけは16分刻みで、それぞれ0.25拍・0.5拍として数えます（|⑥⑦| ＝ 0.5拍）。4拍以外の小節は変換後に一覧表示します。拍数を累積してSMの4拍区切りへ詰め直すため、元の小節線とは一致しない場合があります。変換結果と曲情報を確認してから保存してください。
